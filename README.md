# Barbearia Resende — App de Agendamento

Aplicativo de celular feito em HTML, CSS e JavaScript puro.

## Funções
- Escolher serviço, barbeiro, dia e horário
- Horários já ocupados ficam bloqueados
- Lista "Meus horários" com opção de cancelar
- Dados salvos no próprio celular (localStorage)

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub e envie os arquivos `index.html`, `style.css` e `app.js`.
2. Vá em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. Acesse o link gerado pelo celular.
